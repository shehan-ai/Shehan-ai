## About

I’m Shehan Nilukshan, founder of [Rechazo](https://rechazo.si/), an AI coding agent security company. I’m focused on making AI-powered development safer for the teams building with coding agents.

AI coding agents can work across code, developer machines, and connected services. Rechazo helps teams put security controls around that work by inspecting prompts, monitoring agent actions, and keeping credentials out of conversations.

## What I’m building

| Focus | How it helps |
| --- | --- |
| **Prompt security** | Inspect prompts before sensitive information is sent to an AI agent. |
| **Agent action security** | Monitor and control actions agents take on a developer’s machine. |
| **Credential protection** | Keep secrets out of prompts and scope credentials to the work that needs them. |
| **Team-wide visibility** | Help security and engineering teams understand agent activity and policy decisions. |

Rechazo works alongside coding agents such as Claude Code, Codex, Gemini CLI, Cursor, and Copilot, helping teams use the tools they prefer with stronger security controls.

## Why this matters

AI agents can read files, run commands, and connect to systems using the access available to them. That makes security about more than what an agent says: teams also need to understand what goes into prompts, what actions run, and where credentials can travel.

My goal is to help make AI-powered development useful and secure by default—without getting in the way of how engineers work.
